# FreeCAD MCP Skills

This workspace contains skills for working with FreeCAD via the MCP server.

## Skills Overview

### Core FreeCAD Skills
- **freecad** - General FreeCAD MCP usage, workflows, documentation reference
- **freecad-objects** - Quick reference for Part::Box, Part::Cylinder, etc.

### Matt Pocock Skills (FreeCAD-tailored)
- **f-grill-with-docs** - Interview to sharpen FreeCAD design plans, creates ADRs
- **f-to-spec** - Convert conversation into FreeCAD design spec
- **f-to-tickets** - Break design into FreeCAD f-implementation tickets
- **f-implement** - Create FreeCAD geometry/analysis based on tickets
- **f-code-review** - Review FreeCAD changes against standards and spec

## Workflow

1. **Design**: Use `/f-grill-with-docs` to refine your idea
2. **Spec**: Use `/f-to-spec` to formalize the design
3. **Tickets**: Use `/f-to-tickets` to break into f-implementable units
4. **Implement**: Use `/f-implement` to create FreeCAD objects
5. **Review**: Use `/f-code-review` to verify correctness
